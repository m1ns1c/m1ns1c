## 🗺️ Career Plan

### 📌 단기 목표 (2~3학년)

취업 시장에서 경쟁력을 갖추기 위해 **정보처리기사** 자격증 취득과 **토익 700점 이상** 달성을 목표로 준비하고 있습니다.
AI 분야 논문과 공식 문서를 직접 읽을 수 있는 영어 실력을 갖추기 위해 전공 공부와 병행하며 꾸준히 시간을 투자할 계획입니다.

알고리즘 역량은 **프로그래머스**를 중심으로 매일 꾸준히 문제를 풀며 쌓아가겠습니다.
바쁜 학기 중에도 하루 한 문제라도 놓치지 않는 습관을 만들어, 코딩 테스트 대비와 실무 역량을 동시에 키워나가겠습니다.

포트폴리오 프로젝트는 단순히 동작하는 결과물이 아니라 **실제 문제를 해결하는 수준**으로 완성하는 것을 목표로 합니다.
기획부터 배포까지 직접 고민하며, 다음 두 가지 방향으로 준비할 계획입니다.

- **AI 프로젝트 (주력):** FastAPI 기반 서버와 연동되는 실사용 가능한 AI 서비스를 구현합니다. 데이터 전처리 → 모델 학습 → 배포까지 파이프라인 전 과정을 직접 경험하고, 개선 과정을 GitHub에 모두 기록으로 남기겠습니다.
- **AIoT 프로젝트:** 임베디드 장치로 수집한 센서 데이터를 AI 모델과 연결하는 프로젝트를 제작합니다. 시행착오와 트러블슈팅 경험 자체를 자산으로 삼겠습니다.

### 📌 중기 목표 (3~4학년)

주력 분야인 **AI**에 집중하여 딥러닝 모델 설계, 데이터 전처리, 모델 경량화 등 핵심 역량을 키워나가겠습니다.
동시에 **임베디드 분야도 병행**하며 C 언어 기반 펌웨어 개발과 마이크로컨트롤러 실습을 통해 하드웨어 이해도도 놓치지 않겠습니다.
4학년에는 인턴십 또는 현장실습을 통해 실무 환경을 직접 경험하겠습니다.

### 📌 장기 목표 (졸업 후)

AI 관련 기업 또는 임베디드·AI 융합 분야에 취업하여 실무 역량을 빠르게 쌓는 것을 1차 목표로 합니다.
학부 과정을 통해 AI를 깊이 공부하면서 단순한 기술 적용을 넘어 **연구적 관점에서 문제를 바라보는 것**에도 흥미를 느끼고 있어,
상황에 따라 **대학원 진학을 통해 AI 분야를 더 깊이 탐구하는 것**도 진지하게 고려하고 있습니다.

> 취업이든 대학원이든, 매일 조금씩 성장하는 개발자·연구자가 되겠다는 다짐은 변하지 않을 것입니다.
